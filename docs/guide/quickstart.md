# 快速开始

## 使用流程概览

```
搜索物品 → 查看价格 → 计划制造 → 精炼核算 → 物流运输 → 评估利润
```

## 1. 搜索物品

在左侧导航点击 **🔍 查询**，在搜索框中输入物品名称（支持中/英文模糊匹配）：

- 输入关键词后下拉显示候选列表
- 选择物品后显示多区域价格表格
- **单击价格** → 自动复制到剪贴板
- **双击行** → 展开 Top5 买单 / Top5 卖单

## 2. 估价

点击 **📋 估价**，粘贴游戏内复制的物品数据，快速查询批量价格。

## 3. 制造利润计算

点击 **🏭 制造**，进入工业制造页面：

1. 点击 **蓝图导入** 添加要制造的蓝图
2. 设置材料/成品的 Hub 来源和价格类型
3. 查看生产计划表格中的 19 列完整信息：
   - 单件利润率、个人利润率
   - 材料成本、安装费、税费
   - 生产时长、所需蓝图数

### 关键设置

| 设置 | 说明 |
|------|------|
| Hub 来源 | 材料买入和成品卖出的区域（Jita/Amarr/Dodixie/Rens） |
| 价格类型 | 买单/卖价/均价 |
| 角色配置 | 角色技能等级影响成本计算 |

## 4. 甘特图

切换到 **📊 甘特图** 视图，可视化生产进度时间线。

## 5. 汇总弹窗

点击底部操作按钮查看：

- **采购小助手** — 待采购材料清单及总价
- **所需蓝图表** — 蓝图数量与 ME/TE 要求
- **材料总表** — 所有材料汇总（含库存自动扣减）
- **产出总表** — 成品产出明细
- **人物占用** — 角色时间安排

## 6. 库存管理

点击 **📦 仓库** 管理机库库存：

- 创建机库分类（矿仓、组件仓、产品仓、通用仓库）
- 录入库存物品与加权平均成本
- 管理蓝图库存（BPO/BPC、ME/TE 级别）

## 7. 贸易评分

点击 **⭐ 贸易** 查看贸易机会评分：

- 基于跨区域价差、日均成交量、税收综合评分
- 支持多区域对比贸易路线
- 关注列表：60 秒定时器自动检测价格变化并通知

## 主题切换

应用支持 **One Dark Pro**（暗色）和 **One Light**（亮色）双主题，点击底部状态栏的切换按钮即可一键切换，偏好自动保存。
