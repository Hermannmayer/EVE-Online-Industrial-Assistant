# 快速开始

## 使用流程概览

```
搜索物品 → 查看价格 → 计划制造 → 精炼核算 → 物流运输 → 评估利润
```

## 1. 搜索物品

在左侧导航点击 **🔍 查询**，在搜索框中输入物品名称或 Type ID（英文名按前缀匹配，不区分大小写）：

- 输入关键词后下拉显示**全部**匹配候选（只显示物品名，条数不限、自带滚动）
- **点候选那一条** → 详情面板展开该物品的 5 中心价格 / Top5 买单卖单 / 精炼产物 / 制造材料
- 页面**没有结果表格**：候选就是匹配清单，选中即出详情（回车 = 选第一条）
- 精炼面板顶部可选**人物 / 数量 / 站点**，产率按该人物的提炼技能算

## 2. 估价

点击 **📋 估价**，粘贴游戏内复制的物品数据，快速查询批量价格。

## 3. 制造利润计算

点击 **🏭 制造**，进入工业制造页面：

1. 点击 **蓝图导入** 添加要制造的蓝图
2. 设置材料/成品的 Hub 来源和价格类型
3. 查看生产计划表格中的 19 列完整信息：
   - 单件利润率、个人利润率
   - 材料成本、安装费、税费
   - 生产时长、所需蓝图数

### 关键设置

| 设置 | 说明 |
|------|------|
| Hub 来源 | 材料买入和成品卖出的区域（Jita/Amarr/Dodixie/Rens） |
| 价格类型 | 买单/卖价/均价 |
| 角色配置 | 角色技能等级影响成本计算 |

## 4. 甘特图

切换到 **📊 甘特图** 视图，可视化生产进度时间线。

## 5. 汇总弹窗

点击底部操作按钮查看：

- **采购小助手** — 待采购材料清单及总价
- **所需蓝图表** — 蓝图数量与 ME/TE 要求
- **材料总表** — 所有材料汇总（含库存自动扣减）
- **产出总表** — 成品产出明细
- **人物占用** — 角色时间安排

## 6. 库存管理

点击 **📦 仓库** 管理机库库存：

- 创建机库分类（矿仓、组件仓、产品仓、通用仓库）
- 录入库存物品与加权平均成本
- 管理蓝图库存（BPO/BPC、ME/TE 级别）

## 7. 市场贸易

点击 **⭐ 贸易** 做 **A 贸易中心 → B 贸易中心的全品类价差排行**：

- 选好「从 [中心][买单/卖单] 到 [中心][买单/卖单]」，点 **开始计算**
- 结果按「每方利润」倒序（点表头换列），可用「只看赚钱的」「两侧 ≥ N」筛掉空挂单
- 每行可加入**购物车**（独立置顶窗口，按方向分组）

> 💡 **开始计算不联网** —— 它只读本地已有的价格。这份价新不新，看本页状态栏那一行
> （`Jita 刚刚 / Amarr 3 小时前`）。要更新价格就点**顶栏的「更新价格」**，
> 那是全应用唯一拉取 ESI 价格的入口。

关注列表与价格变化检测是独立的一页：**🔔 价格监控**。

## 主题切换

应用支持 **One Dark Pro**（暗色）和 **One Light**（亮色）双主题，在 **侧边导航 → ⚙ 系统 → 主题** 里选卡片即可即时切换，偏好自动保存。
