## 一、T2 商人助手功能总览（按模块）

### 1. 制造业
| # | 功能 | 一句话说明 |
|---|------|-----------|
| M1 | 基础材料查看 | 查询船名 → 勾选「分解反应产物」→ 显示组件+反应物等基础材料 |
| M2 | 复杂造船规划 | 搜索→添加→规划：确定材料 / 制造步骤 / 每组件流程数；采购小助手给材料需求 |
| M3 | 按库存减流程 | 已有材料放设施、更新库存后，新建勾选「按库存减流程」或右键「子项自动调整流程」 |
| M4 | 并行（改并行数） | 长耗时组件右键改并行数，多线同时造，压缩工期 |
| M5 | 大规模产线并行 | 两种模式：按产线数调整 / 限制子线时间（自动增并行满足工期） |
| M6 | 合并子项 | 多个母项改为同一组号，重复子项自动合并/补缺/流程归零 |
| M7 | 多设施 | 反应/组件/成品可设不同设施；完成后自动转移产品机库到下一级设施 |
| M8 | 备料预定占用 | 勾备料=计算占用，避免「看似够其实不够」；占用按组号从小到大优先 |
| M9 | 逐级制造引导 | 需填料→启动→EVE中已启动→运行中→交付，按子级从高到低 |

### 2. 贸易业
| # | 功能 | 一句话说明 |
|---|------|-----------|
| T1 | 看盘小精灵 | 悬浮窗跟随游戏市场，看价格详情自动出价格图；游戏导出订单自动导入 |
| T2 | 跑商推荐 | 选出发地/目的地/门类 → 生成推荐 → 加入线路（含 4 种挂单思路建议） |
| T3 | 蹲商/蹲站改单推荐 | 出发地=目的地 → 蹲站改单倒卖推荐；拟运数量/量能调整 |
| T4 | 订单导入 | 游戏「我的订单」导出 → 自动导入 → 生成成交记录 |
| T5 | 市场快捷栏 | 物品点击进剪贴板 → 游戏市场粘贴搜索下单 |
| T6 | 赚钱推荐 | 小秘书推荐功能，按类别推荐产品（如 T1 制造） |

### 3. 甘特图 / 项目管理
| # | 功能 | 一句话说明 |
|---|------|-----------|
| G1 | 甘特图 | 横轴时间、项目柱状运行可视化、子级前置自动调整位置 |
| G2 | 夜晚背景条 | 背景灰色条标记夜间时段（18-24 浅灰 / 24-6 深灰），避免凌晨下线 |
| G3 | 同子级对齐 | 同一子级按统一时间启动来规划 |
| G4 | 缩放/时刻提示 | 图缩放；鼠标移动显示时刻、同组反应线/制造线占用 |

### 4. 成本记录
| # | 功能 | 一句话说明 |
|---|------|-----------|
| C1 | 仓库成本自动填写 | 按物资来历（挂收单/市场买/接合同）自动填单个成本 |
| C2 | 挂收单成本 | 两次订单导入→成交记录→成本=收购价+中介费+改单费 |
| C3 | 市场买成本 | 两种：剪切板库存修正（新增按卖单价）/ 交易记录日志粘贴（更精确） |
| C4 | 接合同成本 | 手动添加 或 「估价和精炼」粘贴合同+折扣系数→导入库存 |
| C5 | 加权平均成本累计 | 100@50000 + 50@45000 → 150@(50000×100+45000×50)/150；所有新增操作通用 |
| C6 | 行星开发成本 | 行星工业瞬间转化，扣材料加成品，成本继承材料+海关税 |
| C7 | 制造成本 | 启动扣库存材料，完成加成品，成本继承材料库存成本 |
| C8 | 制造业成本明细 | 右键查看；材料来源三种（子项/库存/市场购买）合并+启动费+蓝图费 |
| C9 | 移库成本 | 剪切板修正→新增物品选「物资来源于其他机库」→B 继承 A 成本 |

## 三、高优先级借鉴建议（含实现思路）

### 1. 订单导入 + 成交记录（成本核心，T4 / C2）
- **现状**：无。玩家市场买/挂收单无法自动记成本。
- **借鉴思路**：
  - 用户在游戏「我的订单」导出订单（文本）→ 助手解析为 {物品, 数量, 方向(买卖), 价格, 状态}。
  - 与本地订单快照对比 → 生成「成交记录」：买单成交=库存增加，成本=收购价（+中介费/改单费）；卖单成交=库存减少。
  - 落地：新服务 `services/order_import.py`（纯函数解析 + diff）+ UI 入口（仓库页按钮或独立弹窗）。复用现有 `add_item` 加权平均成本。
- **收益**：解决「市场买/挂收单成本怎么记」这一高频痛点，直接对齐 T2 附录 1。

### 2. 交易记录日志粘贴（成本更精确，C3b）
- **现状**：`库存修正`（剪贴板全量比对）会把新增物品按**市场卖价**记成本，与实际成交价有偏差。
- **借鉴思路**：新增「交易记录日志粘贴」：粘贴游戏交易日志（含价格）→ 按日志中的**成交价**入库/记成本。比剪贴板精确。
- **落地**：在 `review_dialog.py` 或新弹窗加一个日志解析入口，解析出 {type_id, qty, price} 后复用 `add_item(price=日志价)`。

### 3. 看盘小精灵（用户粘性，T1）
- **现状**：无。看价格要切游戏/助手。
- **借鉴思路**：做一个置顶悬浮窗，跟随游戏市场窗口；读取游戏剪贴板/焦点窗口识别当前查看物品 → 显示该物品价格图 + 涨跌。受限于游戏客户端交互，落地复杂度高，可先做「悬浮价格卡片」（按剪贴板物品显示价格），后续再尝试自动跟随。

### 4. 跑商/蹲商推荐（贸易玩法，T2/T3）
- **现状**：贸易页仅市场数据浏览，无「倒卖推荐」。
- **借鉴思路**：选出发地/目的地/门类 → 对比两区域价格差 → 按利润率/量能排序生成「线路推荐」，勾选加入清单 → 联动采购小助手 + 移库。
- **落地**：新 `services/trade_recommend.py`（价格差计算纯函数，可单测）+ 贸易页推荐面板。蹲商=出发地==目的地（同区域买卖价差）。

### 5. 接合同粘贴导入（C4）
- **现状**：合同页存在；「粘贴合同导入库存」待确认。
- **借鉴思路**：「估价和精炼」粘贴合同文本 + 折扣系数 → 解析多条目 {物品, 数量, 单价} → 导入库存（`add_item` 记成本）。

### 6. 甘特图增强（G2/G3/G4）
- **现状**：`gantt_view` 为基础版（柱状图+小时网格）。
- **借鉴思路**：加**夜间背景条**（18-24 浅灰 / 24-6 深灰）、**同子级对齐**开关、**缩放**。低风险纯视图增强，收益直观（避免凌晨下线）。

### 7. 大规模产线并行「按时间」模式（M5b）
- **现状**：有 `smart_parallel_children`；是否支持「限制子线时间→自动增并行」待确认。
- **借鉴思路**：确认/补齐「按目标时长反推并行数」模式，配合甘特图查看效果。

## 四、暂缓 / 低优先级

| 功能 | 原因 |
|------|------|
| 市场快捷栏 (T5) | 纯交互便捷性，价值一般 |
| 行星工业瞬间转化 (C6) | 需要行星工业数据接入，投入大 |
| 多设施自动转移产品机库 (M7) | 依赖游戏侧运输，助手只能提示，收益有限；可先做「完成后提示手动转移」 |

## 五、结论

- **已有且等价**：加权平均成本、剪贴板库存修正、移库继承成本、制造完成入库、成本明细、甘特图基础版、采购小助手、填料总表、备料占用、并行调整、批量设成本。
- **本次已新增**（对齐 T2）：库存修正、移库对话框、批量成本（市场价×折扣）、下线确认弹窗+机库选择、状态列待下线按钮、移库继承成本。
- **最值得下一步做**（按性价比排序）：
  1. **订单导入 + 成交记录**（成本准确性，高价值）
  2. **交易记录日志粘贴**（成本精确化，复用度高）
  3. **跑商/蹲商推荐**（贸易玩法，纯函数可测）
  4. **甘特图夜晚背景 + 同子级对齐**（低风险视图增强）
  5. 看盘小精灵（先做剪贴板驱动的悬浮价格卡片）
