# 界面总览

## 主窗口布局

主窗口采用 **侧边导航 + 内容区 + 底部状态栏** 的三栏布局：

```
┌──────────────────────────────────────────────┐
│  侧边导航  │          内容区                  │
│            │                                  │
│  📋 估价   │  根据所选页面显示不同内容          │
│  🔍 查询   │                                  │
│  🏭 制造   │                                  │
│  ⭐ 贸易   │                                  │
│  📦 仓库   │                                  │
│            │                                  │
├──────────────────────────────────────────────┤
│  状态栏: 价格更新时间 | 🔄更新 | 进度条 | ⚙设置 │
└──────────────────────────────────────────────┘
```

## 导航页面

| 导航项 | 页面 | 主要功能 |
|--------|------|----------|
| 📋 估价 | `estimate_view` | 剪贴板粘贴 → 批量价格查询 |
| 🔍 查询 | `query_view` → `query_page` | 物品搜索、价格表格、深度订单、走势图、CSV/Excel 导出 |
| 🏭 制造 | `industry_view` | 生产计划管理、蓝图搜索、成本核算、甘特图、多种汇总弹窗 |
| ⭐ 贸易 | `trade_view` | 贸易评分、跨区域对比、关注列表、价格变化检测 |
| 📦 仓库 | `inventory_view` → `inventory_page` | 机库管理、库存 CRUD、蓝图管理（BPO/BPC、ME/TE） |

## 底部状态栏

状态栏显示以下信息（`industry/status_bar.py`）：

| 区域 | 功能 |
|------|------|
| 价格更新时间 | 最后一次成功拉取 ESI 市场价格的时间 |
| 更新按钮 | 手动触发价格更新 |
| 进度条 | 数据初始化/价格更新进度（阶段文字 + 进度条）|
| 自动更新开关 | 开启/关闭定时自动更新（0-1440 分钟间隔可配）|
| 主题切换 | 一键切换 One Dark Pro / One Light |

## 设置对话框

点击状态栏 ⚙ 打开设置面板（`settings_view.py`）：

- **主题切换**：One Dark Pro（暗色）/ One Light（亮色）
- **自动更新**：开关 + 间隔配置
- **数据初始化**：拉取 SDE/ESI 数据
- **关于**：版本信息

## 子窗口与弹窗

应用使用多种弹窗辅助信息展示：

| 弹窗 | 位置 | 说明 |
|------|------|------|
| 启动检查 | 启动时 | `StartupCheckDialog` — 检测数据就绪状态，按需自动初始化 |
| 成本明细 | 制造页 | 按游戏类目拆分安装费明细 |
| 材料总表 | 制造页 | 所有生产计划的材料汇总 |
| 采购小助手 | 制造页 | 待采购清单 + 当前库存对比 |
| 所需蓝图 | 制造页 | 蓝图数量、ME/TE 要求汇总 |
| 产出总表 | 制造页 | 成品产出明细 |
| 人物占用 | 制造页 | 角色在各生产计划中的时间占用 |
| 价格走势 | 查询页 | 历史价格趋势折线图 |
| 深度订单 | 查询页 | Top5 买单/卖单详情 |
| 代采购管理 | 制造页 | 第四 Tab，管理代采购订单与供应商 |
