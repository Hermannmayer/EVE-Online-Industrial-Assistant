# 界面总览

## 主窗口布局

主窗口采用 **侧边导航 + 内容区 + 底部状态栏** 的三栏布局，标题行下方还有一条
**主工具栏**（价格与更新的唯一入口，见下节）：

```
┌──────────────────────────────────────────────┐
│  标题行                    ─  □  ✕            │
├──────────────────────────────────────────────┤
│  区域 | 价格时效 | 自动更新      🔄 更新价格    │  ← 主工具栏
├────────────┬─────────────────────────────────┤
│ 侧边导航    │          内容区                  │
│  📋 估价    │                                  │
│  🔍 查询    │  根据所选页面显示不同内容          │
│  🏭 制造    │                                  │
│  ⭐ 贸易    │                                  │
│  🔔 监控    │                                  │
│  📦 仓库    │                                  │
├────────────┴─────────────────────────────────┤
│  状态栏: 阶段文案 / 当前操作提示     [进度条]   │
└──────────────────────────────────────────────┘
```

## 导航页面

| 导航项 | 页面 | 主要功能 |
|--------|------|----------|
| 📋 估价 | `estimate_view` | 剪贴板粘贴 → 批量价格查询 |
| 🔍 查询 | `query_view` → `query_page` | 物品搜索、价格表格、深度订单、走势图、CSV/Excel 导出 |
| 🏭 制造 | `industry_view` | 生产计划管理、蓝图搜索、成本核算、甘特图、多种汇总弹窗 |
| ⭐ 贸易 | `trade_view` | A→B 全品类价差排行。**只读本地已存价格**，用顶栏「更新价格」刷新；价格时效显示在本页状态栏 |
| 📦 仓库 | `inventory_view` → `inventory_page` | 机库管理、库存 CRUD、蓝图管理（BPO/BPC、ME/TE） |

> 🔍 **查询页**（空闲态仪表盘 + 有结果态详情）的详细用法见 [query.md](query.md)。

## 主工具栏（价格）

主工具栏（标题行下方那一行，`ui_qml/qml/shell/Main.qml`）左侧是「状态与上下文」，
右侧只有**一个**动作：

| 区域 | 功能 |
|------|------|
| 区域勾选 | 选择「更新价格」要覆盖哪些贸易中心 |
| 价格时效 | 最后一次成功拉取 ESI 市场价格的时间（绿/黄/红三档） |
| 自动更新开关 | 开启/关闭定时自动更新（0-1440 分钟间隔可配） |
| **更新价格** | **手动触发价格更新的唯一入口** —— 页面自身不拉取全量价格 |

进度条与阶段文字在触发更新后显示；主题切换在设置面板里。

## 设置对话框

点击侧边导航底部的 **⚙ 系统** 打开设置面板
（`ui_qml/bridge/settings_bridge.py` + `qml/dialogs/SettingsDialog.qml`）：

- **主题切换**：One Dark Pro（暗色）/ One Light（亮色）
- **自动更新**：开关 + 间隔配置
- **数据初始化**：拉取 SDE/ESI 数据
- **关于**：版本信息

## 子窗口与弹窗

应用使用多种弹窗辅助信息展示：

| 弹窗 | 位置 | 说明 |
|------|------|------|
| 启动检查 | 启动时 | `InitWizard`（自动模式）— 检测数据就绪状态，全部就绪自动关闭，缺失时自动初始化 |
| 成本明细 | 制造页 | 按游戏类目拆分安装费明细 |
| 材料总表 | 制造页 | 所有生产计划的材料汇总 |
| 采购小助手 | 制造页 | 待采购清单（总需求 / 需采购 / 买卖差价 / 总价） |
| 所需蓝图 | 制造页 | 蓝图数量、ME/TE 要求汇总 |
| 产出总表 | 制造页 | 成品产出明细 |
| 人物占用 | 制造页 | 每人物一块的产线占用（制造/科研/反应三行容量条，按**已规划**统计：待生产/生产中/待下线的计划都算占线） |
| 价格走势 | 查询页 | 历史价格趋势折线图 |
| 深度订单 | 查询页 | Top5 买单/卖单详情 |
| 代采购管理 | 制造页 | 第四 Tab，管理代采购订单与供应商 |

> 只读汇总表（**所需蓝图 / 材料总表 / 产出总表 / 材料覆盖 / 研究分析**）**双击任一格 = 复制那一格的文字**，
> 往游戏里搜蓝图名 / 物品名时用（复制的是屏幕上显示的文本，即带千分位的那一份）。
