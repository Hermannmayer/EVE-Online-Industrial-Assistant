# 物品查询

查询页用来**搜一件物品、看它的价格和行情**。它有两种样子，什么时候显示哪一种，全看「当前有没有搜到东西」：

- **没搜 / 没搜到** → 显示**空闲态仪表盘**（产线详情 / 资产折线图 / 挂单列表）
- **搜到了** → 显示**结果表 + 详情面板**（5 个贸易中心价格 / 订单 / 精炼 / 制造材料）

所以这个页面既是「查价工具」，也是你**打开软件后的第一屏** —— 不查东西的时候，它就当仪表盘用。

## 搜物品

1. 顶部搜索框输入**名称 / ID / 类别**，边打字边出候选（也可以直接按回车搜）
2. 点「搜索」（或回车）出结果
3. 结果表**点击一行**选中 —— 下方详情面板立刻换成这件物品的数据

搜索框下面还有几个按钮：

| 按钮 | 作用 |
|------|------|
| 全物品 | 打开全物品浏览器，按类别翻 |
| 批量查价 | 一次查多个物品的价格 |
| 清空 | 清掉结果，回到空闲态仪表盘 |
| 区域（右上角下拉）| 换查询 / 详情用的贸易中心 |

> 💡 搜索框空着的时候，会把你**搜过的历史**列出来，点一下就搜。

## 搜到之后：详情面板

选中一行后，下半屏是**四块面板**（左上 / 右上 / 左下 / 右下）：

- **左上 · 5 个默认贸易中心的价格**：Jita / Amarr / Dodixie / Rens / Hek 挨个列出买单卖单价，
  带柱形条，左侧的小圆点表示该中心属于哪个帝国。**最便宜 / 最贵**的那一格会标出来。
- **右上 · 订单列表**：实时从 ESI 拉的最优订单，**卖单和买单分两列**，
  每边上各有一个「复制最优价」按钮，点一下就把价格抄进剪贴板。
- **左下 · 精炼产物、价格**：这件物品拆掉能出什么矿、各值多少，底部给总计与利润。
  不能精炼的物品会写明「该物品不可精炼」。
- **右下 · 制造所需的材料**：造它要哪些料、各值多少。上面有**制造数量**输入框和
  **价格中心**下拉框 —— 改这两个，整张表跟着重算；底部给按卖价 / 买价算的合计。

> 💡 右键结果表的行，还有复制名称 / Type ID / 买单价 / 卖单价 / 整行、查看实时订单、
> 跳去工业页看配方等操作。双击一行 = 看实时订单。

## 没搜的时候：仪表盘

不查东西时，主区域是三块横排的面板。

### 产线详情

**按产线类型分行**（制造 / 科研 / 反应），每行是一条容量条：

- 条子里**一个角色占一段**，段内一个小格代表一条产线 —— 用了几个就点亮几个，
  一眼能看出**是谁在用、用了几个**。数字是「已用 / 上限」。
- 面板太窄、格子画不清时，会**降级**成一条按占用比例填充的整条（信息不丢，
  把鼠标停在行上能看到逐角色的数字）。

下面还有**快捷操作**列表，列出「可启动」和「可下线」的产线，点行内按钮即可：

- 点**启动 / 下线**会先弹一个确认框，确认后才执行。
- 缺料、缺蓝图流程的产线也会出现在这里（按钮仍可点，和产线启动小助手一个口径）。

### 资产折线图

四条线，各代表一项资产：

| 线 | 含义 |
|----|------|
| 总资产 | 下面三项之和 |
| 挂单金额 | 你所有挂单的当前价值 |
| 库存材料 | 各机库材料按卖单价估值 |
| 钱包余额 | 你自己填的数字（见下） |

- **点底部的图例**可切换某条线的显示 / 隐藏（至少留一条）。
  隐藏后纵轴刻度会跟着剩下的线变 —— 免得被数量级大的那条压成一条直线。
- **时间跨度**四档：近 7 天 / 本月 / 本年 / 总。
- 上面的「资产（表格显示）」列出各线最新值，以及相对**区间起点**涨跌了多少。

> ⚠️ **数据从你第一次记录那天开始按天累积** —— 刚开始只有零星几个点，
> 不是坏了。导入一次挂单、或者填一次钱包余额，就把今天这一天记下来了。

### 挂单列表

这块管的是你**游戏里的挂单**，数据来自你从游戏里导出的文件。

**怎么用（三步）：**

1. 进游戏，打开 **钱包 → 订单**，点**导出**按钮 —— 游戏会在
   `我的文档\EVE\logs\Marketlogs\` 写一个文件（国服文件名形如
   `个人订单-2026.09.16 1232.txt`）。
2. 回到软件，点面板上的 **「读取订单」**。它会自动找那个目录里**最新**的一份来读。
   - 目录不一样？在下面的 **「导出目录」** 输入框填你自己的路径，点「应用」。
3. 读进来后，列表会显示每笔挂单的**物品 / 买还是卖 / 价格 / 剩余 / 位置**，底部给汇总。

读完之后，如果你库里有些**旧订单没出现在这次的导出文件里**（多半是已经成交或撤单了），
软件会弹个框问你要不要**把它们标记为已结束**。**选「否」就原样保留** ——
因为你也可能只是导出了另一个角色的订单，不能自动删。

**钱包余额**：这一项**要手填**（游戏导出文件里没有它）。在
「钱包余额」框里填当前 ISK（可带千分位，如 `1,234,567.89`），点「记录」。
它会存进设置、并记一条资产快照，参与上面的折线图。

> 💡 反复导入同一份文件是**幂等**的 —— 用订单 ID 去重，不会越读越多。
> 挂单金额和库存材料这两项，每次「读取订单」或「记录钱包余额」时都会跟着重新记一遍。

## 常见问题

- **「读取订单」说没找到文件？** 先确认游戏里点过导出，再看文件名是不是含
  `order` 或 `订单`；目录不对就在「导出目录」里改。
- **资产折线图是空的？** 还没记过任何快照 —— 导入一次挂单或填一次钱包余额即可。
- **订单列表的「物品」列是空的？** 不会 —— 软件会用 Type ID 去 SDE 补中文名；
  真缺了说明本地 SDE 数据没导全（跑一次数据初始化）。
- **挂单价格要手动填吗？** 不用，价格 / 数量 / 位置都从导出文件读；只有**钱包余额**要手填。
