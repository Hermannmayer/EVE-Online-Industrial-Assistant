## 主题系统

### 配色方案：One Dark Pro（暗色） / One Light（亮色）

全 QSS 样式表驱动，支持运行时切换。

暗色主题关键色值：

| 变量 | 色值 | 用途 |
|------|------|------|
| BG_DARK | `#282c34` | 窗口背景 |
| BG_SURFACE | `#21252b` | 面板/卡片背景 |
| PRIMARY | `#61afef` | 主色调/高亮 |
| ACCENT_GREEN | `#98c379` | 正数/利润 |
| ACCENT_RED | `#e06c75` | 负数/亏损 |
| TEXT_PRIMARY | `#abb2bf` | 主文字 |
| TEXT_SECONDARY | `#5c6370` | 次要文字 |
| BORDER | `#3e4452` | 边框/分割线 |

**实现文件：** `theme.py`（~600 行 QSS）

## 对话框

| 弹窗 | 用途 |
|------|------|
