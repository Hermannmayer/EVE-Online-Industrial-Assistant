# EVE 商人助手 — 功能规格

> 更新：2026-06-28
> 按实际代码完成度编写，标注已砍、未做、占位

## 一、物品查询（核心功能 — 已完成）

| 功能 | 说明 |
|------|------|
| 模糊搜索 | 输入中/英文名实时下拉候选 |
| 类别搜索 | 输入类别名自动展示该类别所有物品 |
| 结果表格 | 显示图标、ID、中/英文名、类别、买单/卖单/均价、体积 |
| 订单数量 | 价格后括号显示该方向订单数量 |
| 单击复制 | 单击任意价格自动复制到剪贴板 |
| 深度订单 | 双击行展开 Top5 买单/卖单（实时 ESI 拉取） |
| 列排序 | 单击表头按 ID、价格、均价等排序 |
| 搜索历史 | 聚焦搜索框显示最近 20 条记录 |
| 倒挂高亮 | 买单高于卖单时行背景高亮 |

**实现文件：** `ui_pyside6/views/query_view.py`

## 二、工业制造（部分完成）

### 已实现
| 功能 | 说明 |
|------|------|
| 搜索成品 + 材料表 | 搜索成品，显示蓝图材料清单 |
| 成本计算 | 基于 market_prices 算材料成本 |
| 利润摘要 | 成本/收入/利润/ROI/小时利润 |
| 制造评分 | 完整的费率计算（ME/TE/技能/设施修正） |
| 评分缓存 | 评分结果定时刷新 |
| 工业系统成本指数 | 从 ESI 拉取写入数据库 |

### 占位/待做
| 功能 | 说明 |
|------|------|
| 利润排行 | 所有可制造物品按利润率排序 |
| BOM 多层展开 | 递归查 blueprint_products，展开 T2 产业链 |
| 批量对比 | 多个成品同时显示利润对比 |
| 生产计划 | 排产管理 |

**实现文件：**
- `ui_pyside6/views/industry_view.py` — UI
- `services/scoring.py` — 评分引擎
- `services/scoring_cache.py` — 缓存
- `services/workers/getindustry.py` — 工业数据拉取

## 三、贸易评分系统（部分完成）

| 功能 | 说明 |
|------|------|
| 利润评分 | 基于跨区域价差、日均成交量、税收综合评分 |
| 跨区域价格 | 支持 4 个贸易中心（Jita/Amarr/Dodixie/Rens） |
| 每日真实利润 | 考虑税费、经纪费后的净利评估 |
| 多角色支持 | 管理角色技能、所在地和资金配置 |
| 排序与筛选 | 按评分、利润率、成交量等多维度排序 |

**实现文件：** `services/scoring.py`（贸易评分与制造评分共用）
