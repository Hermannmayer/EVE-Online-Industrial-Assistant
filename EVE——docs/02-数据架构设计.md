### 2.1 数据集总览

整个系统按数据性质划分为 6 个数据集：

```
数据集划分
├── 静态数据 — 物品/蓝图/星图（启动加载，只读）
│   ├── 商品通用（items）：17 万+ 物品
│   ├── BP_Main（blueprints）：所有蓝图
│   ├── RegionMark：市场区域
│   └── P_AdvCaseP2/P4：高级方案
│
├── 蓝图数据 — 蓝图扩展信息
│   ├── BP_Main 补充字段
│   ├── Chain_M_MID / Chain_I_MID（产业链链式）
│   └── IsReact（反应标记）
│
├── 星图 — 星系/空间站/跳桥
│   ├── solar_systems
│   ├── stations
│   └── region_connections
│
├── 运行时数据 — 用户业务数据（13 张表）
│   ├── 生产计划、通用设置
│   ├── 行星总表/详表/仓库
│   ├── 机库总表、人物总表、技能表
│   ├── 库存物品、订单成本、成交记录
│   ├── 倒卖计划、蓝图表
│   └── StationRegion
│
├── ESI 缓存 — 市场价格/成交量缓存
│   ├── PV / PVMore（价格）
│   ├── Vol / VolMore（成交量）
│   ├── TimeStamps（数据加工时间戳+就绪标记）
│   ├── SystemIndex（工业系统指数）
│   └── AdjustedPrice / EIV
│
└── 用户配置
    ├── DealerSetting（100+ 配置项）
    └── 角色配置（多角色/技能/声望）
```

### 2.2 核心表结构详解

#### 物品表（items / 商品通用）

| 列名 | 类型 | 说明 |
|------|------|------|
| type_id | INTEGER PK | EVE 物品 ID |
| name | TEXT | 中文名 |
| en_name | TEXT | 英文名 |
| group_id | INTEGER | 物品组 ID |
| market_group_id | INTEGER | 市场分类 ID |
| volume | REAL | 体积 m³ |
| packaged_volume | REAL | 打包体积 |
| meta_group_id | INTEGER | 元组（1=T1, 2=T2, 3=故事线等） |
| base_price | REAL | 基础价格 |
| blueprint_id | INTEGER | 关联蓝图 typeID |

#### 蓝图主表（BP_Main）

| 列名 | 类型 | 说明 |
|------|------|------|
| blueprint_id | INTEGER PK | 蓝图 typeID |
| product_id | INTEGER | 产品 typeID |
| tech_level | INTEGER | 科技等级 |
| is_reaction | INTEGER | 是否反应（0=制造, 1=化学反应, 2=聚合反应） |
| manufacture_time | INTEGER | 制造时间（秒） |
| waste_factor | INTEGER | 浪费因子（T1=10, T2=2） |
| max_production_limit | INTEGER | 最大并行限制 |
| research_material_time | INTEGER | ME 研究时间 |
| research_copy_time | INTEGER | 拷贝时间 |
| invention_time | INTEGER | 发明时间 |
| productivity_modifier | REAL | 生产效率修正 |
| chain_m_mid | TEXT | 制造产业链子件 ID（逗号分隔） |
| chain_m_mcount | TEXT | 制造产业链子件数量 |
| chain_i_mid | TEXT | 发明产业链子件 ID |

#### 蓝图材料表（blueprint_materials）

| 列名 | 类型 | 说明 |

#### 运行时数据（13 张表）

### 2.4 配置项（DealerSetting 参考）

制造模块配置：
- OFMode: 服务器模式（0=WY, 1=TQ, 2=SG）
- PriceMatRegion / PriceProRegion: 原料/产品购买区域
- IMatBybuy / IProBybuy: 是否用买入价（vs 卖出价）
- IMatDiscount / IProDiscount: 折扣率
- IMatFeePerM3 / IProFeePerM3: 运费/立方米
- AutoDissasemble, ReactorDissasemble, PlanetDissasemble: 拆解选项
- DefaultChar: 默认角色
- SetDefaultHour: 默认完成小时

市场模块配置：
- AutoUpPrice_MaxSecond: 自动更新间隔
- ShowOrderCompare: 是否显示订单对比
- ClearSellRecord: 是否清除旧记录
