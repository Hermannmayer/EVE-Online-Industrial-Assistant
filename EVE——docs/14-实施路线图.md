## 14.2 修正后的开发计划

### 短期（当前可立即做的）

| 优先级 | 功能 | 说明 | 工作量 |
|--------|------|------|--------|
| P0 | **ME/TE 制造评分优化** | 在 scoring.py 加入 ME 浪费因子修正、TE 时间修正 | 1-2 天 |
| P0 | **评分 UI 展示** | 在 industry_page 展示评分 breakdown，增加排序 | 2-3 天 |
| P1 | **利润排行列表** | 在 industry_page 加一个 Tab：所有可制造物品按利润率排序 | 3-5 天 |
| P1 | **多区域价格切换** | industry_view 支持选择原料/产品区域 | 1-2 天 |

### 中期（1-2 周）

| 功能 | 说明 |
|------|------|
| **BOM 多层展开** | 递归查 blueprint_products，展开 T2 产业链 |
| **批量对比模式** | 选择多个成品，同时显示利润对比 |
| **蓝图管理页** | 导入/浏览用户拥有的蓝图 |
| **订单管理** | 基于 market_prices 的简单订单簿 |
| **价格监控** | 关注列表 + 价格变化提醒 |

### 长期（3-4 周+）

| 功能 | 说明 |
|------|------|
| 置顶窗口 | 自动购买、制造运行器 |
| 运输分析 | 跨区域价差 + 运费计算 |
| 报表图表 | matplotlib 嵌入价格走势 |
| 设置页完善 | 代理/Debug/更新配置 |
