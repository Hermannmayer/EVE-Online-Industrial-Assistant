## 上篇：参考设计层

### 4.1 制造流程总览

```
用户选择产品
    │
    ▼
1. 查找蓝图（blueprints.BP_Main）
    │
    ▼
2. 展开 BOM（材料清单）
    ├─ 2.1 直接材料（blueprint_materials 表）
    ├─ 2.2 子件递归（Chain_M_MID 产业链展开）
    │   ├─ 每层查子件的蓝图
    │   ├─ 如果子件仍是中间件 → 继续展开
    │   └─ 直到基础材料（矿石/反应物）
    └─ 2.3 反应材料（IsReact=1/2 标记）
    │
    ▼
3. 获取当前市场价格
    ├─ 材料买入价（原料区域 PriceMatRegion）
    └─ 产品卖出价（产品区域 PriceProRegion）
    │
    ▼
4. 计算成本
    ├─ 材料成本 = Σ(材料数量 × 单价)
    ├─ 时间成本 = 制造时间 × ISK/秒费率
    ├─ 运费 = 体积 × 运价
    └─ 税费 = (成本 + 运费) × 税率
    │
    ▼
5. 利润分析
    ├─ 毛利润 = 收入 - 成本
    ├─ 毛利率 = 利润 / 成本 × 100%
    └─ ROI = 利润 / 投资 × 100%
    │
    ▼
6. 排产计划（可选）
    ├─ 选择设施（GClass75 设施管理）
    ├─ 分配角色（GClass1 角色税率）
    ├─ 分配制造槽（GClass80 产能计算）
    └─ 排入时间线（贪心算法）
```

#### 4.3.1 材料需求公式（ME 修正）

```csharp
// GClass55.smethod_8 — 材料数量计算
public static double smethod_8(long base_qty, int me_level, 
                                GClass70 config, double batch_runs) {
    // base_qty: 蓝图基础材料数量
    // 公式:
    // waste_factor = blueprint.waste_factor (T1=10, T2=2)
    // if me_level >= 0:
    //     effective_waste = waste_factor - waste_factor / (me_level + 1)
    //     effective_waste = max(effective_waste, 0)
    // else:
    //     effective_waste = waste_factor
    //
    // adjusted_qty = ceiling(base_qty × (1 + effective_waste / 100))
    // total = ceiling(adjusted_qty × batch_runs)
    //
    // 例如:
    // base=100, waste=10%, ME=0 → ceil(100 × 1.10) = 110
    // base=100, waste=10%, ME=10 → ceil(100 × 1.009) = 101
}
```

#### 4.3.2 制造时间公式（TE 修正）

```csharp
// GClass55.smethod_7 — 制造时间计算
public static double smethod_7(int type_id) {
    // 从 BP_Main 获取: manufacture_time, productivity_modifier
    // base_time = manufacture_time（秒）
    //
    // TE 修正:
    // TE_factor = 1 - (0.05 × TE) / (1 + 0.05 × TE)
    // TE=0 → 1.0 (0% 减少)
    // TE=10 → 0.75 (-25%)
    // TE=20 → 0.50 (-50%)
    //
    // 工业指数修正:
    // system_index = SystemIndex[system_id].manufacturing
    // final_time = base_time × TE_factor × (1 + system_index)
    //
    // 最终时间(小时) = final_time × runs × parallels / 3600
}
```

#### 4.3.3 时间成本公式

```csharp
// GClass55.smethod_1 — 制造时间成本
public static double smethod_1(int type_id, double isk_per_second, 
                                long seconds, double tax) {
    // 两种计算模式:
    if (int_0 == 0) {
        // 模式0: 固定比例税
        // 成本 = 时间(秒) × isk费率 × 数量 × (1 + 税率)
        return isk_per_second × seconds × batch × (1 + tax);
    } else {
        // 模式1: 线性税
        // 成本 = 时间(秒) × 数量 × (税率 + isk费率 + double_0)
        return isk_per_second × seconds × batch × (tax + isk_per_second + double_0);
    }
}
```

### 4.5 批量排产算法

#### 4.5.1 约束条件

```
输入: 产品列表 [{type_id, runs, parallels, facility, char}, ...]
约束:
  1. 每个角色有固定数量的制造槽（由技能决定）
     - 批量生产学 → 每级 +1 槽
     - 高级量产技术 → 每级 +1 槽
     - 基础槽数 = 1
  2. 每个设施有最大并行数（挂起点限制）
     - NPC 空间站：~10 个
     - 玩家哨站：更多
  3. 每个产品有制造时间（受 TE + 工业指数影响）
  4. 某些产品只能在特定设施制造
  5. 时间线约束：一个槽同一时间只能做一个产品
```

#### 4.5.2 贪心排产算法（Dlg_IndutMultiAuto）

```csharp
// GClass55.smethod_11 — 主入口
// 输入: 排产参数 GClass64
// 输出: 排产结果 DataTable
//
// 算法:
// 1. smethod_12: 按 sublevel（子组）分组
//    每组内的产品共享同一套材料，优先排完一组再排下一组
//
// 2. 每组内:
//    a. 按利润率降序排序
//    b. 对每个产品:
//       - 找可用槽（角色+设施）
//       - 最早可用时间 = max(角色可用时间, 设施可用时间)
//       - 分配并更新槽位时间
//    c. 继续下一个产品
//
// 3. smethod_16: 货运+运行调配
//    - 检查材料是否在正确设施
//    - 如果需要运输，均摊运费和时间
//
// 4. smethod_18: 写入生产计划表
//    - 每行一条制造任务
//    - 包含: 产品/数量/设施/角色/开始时间/完成时间/状态

// GClass55.smethod_12 — 单组排产

// 
// 里面的细节:
// smethod_9 — 计算单次制造时间(含技能修正)
// smethod_8 — 计算材料数量(含ME修正)
```
