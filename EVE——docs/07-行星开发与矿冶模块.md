#### 7.1.2 PI 产品层级

```
P0 (基础资源) → 只能从行星提取，不能制造
  碳化合物、碳化物、… 等基础元素和化合物

P1 (一级产物) → P0 × 2 合成
  细菌(2393)、蛋白质(2396)、… 等生物制品

P2 (二级产物) → P1 × 2 → P2
  生物燃料(3683)、生物质(3685)、… 等材料

P3 (三级产物) → P2 × 2 → P3
  数据芯片(3728)、冷却剂(9832)、… 等组件

P4 (最终产物) → P3 × 2 → P4
  完整机库精炼阵列(2867)、散热槽(9838)、…
```

### 7.2 矿物精炼（frmOreProcessing）

#### 7.2.1 精炼公式

```
实际回收率 = 基础回收率(50%) × (1 + 0.03 × 精炼学技能)
                              × (1 + 0.02 × 精炼效率技能)
                              × (1 + 植入体加成)
                              × (1 - 空间站税)

每种矿石有固定的成分产出表:
- 凡晶石 → 三钛合金
- 灼烧石 → 三钛合金
- 干焦岩 → 三钛合金 + 类银超金属
- 等等...
```

#### 7.2.2 精炼产出计算

```
输入矿石 + 数量
  │
  ▼
查矿石成分表（每种矿石固定成分）
  │
  ▼
实际产出 = 基础产出 × 实际回收率
  │
  ▼
输出各种矿物及数量

同时计算:
- 市场价评估产出总价值
- 判断值不值得精炼
- 显示最佳精炼站（最高回收率）
```

### 7.3 拆解回收（PageRecycler）

T2 装备/模块拆解为组件材料：

```
输入 T2 装备
  │
  ▼
查拆解配方（每种 T2 装备有固定拆解产出）
  │
  ▼
产出: 等级装备碎片 / 反应物 / T1 组件 / 材料

拆解是否划算:
  产出总价值 > 装备成本 → 有利可图
```
