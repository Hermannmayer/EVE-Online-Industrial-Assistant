### 10.2 ESI 定价拉取（DataUpESI）

#### 10.2.1 拉取流程

```
DataUpESI 是一个带 UI 的窗口，运行主循环:

OnLoad:
  1. 从 RegionMark 读取所有配置的区域
  2. 初始化 PV / Vol / PVMore / VolMore / TimeStamps 缓存表
  3. 启动 market_timer（~60 秒间隔）

OnTimer:
  for each region in 交易区域列表:
    1. 查 TimeStampsWEIGHT[region].DelaySec
    2. 如果距今 > DelaySec:
      3. 拉取 /markets/{region}/orders/?order_type=sell（多页）
      4. 拉取 /markets/{region}/orders/?order_type=buy（多页）
      5. 聚合计算:
         sell = min(订单价格)       // 最低卖价
         buy = max(订单价格)        // 最高买价
         sell_vol = sum(卖单剩余量) // 卖方深度
         buy_vol = sum(买单剩余量)  // 买方深度
         sell_count = 卖单数       // 卖方挂单密度
         buy_count = 买单数
         sell_avg = 加权均价
         buy_avg = 加权均价
      6. 写入 PV/PVMore 表
      7. 拉取 /markets/{region}/history/（成交量历史 30 天）
      8. 计算 volume_30, avg_price_30, bs(买卖比)
      9. 写入 Vol/VolMore 表
      10. 标记该区域更新完成
      end
  end
  所有区域完成 → 更新 TimeStamps → 标记 ready
```

### 10.8 实际后台机制

采用更简洁的模式：启动检查 + 按需更新，没有全局定时器循环。

```python
# MainWindow.__init__ → _init_price_check()
# 1. PriceCheckWorker(QThread):
#    SELECT MAX(fetch_time) FROM market_prices
#    距今 > 30 分钟 → 需要更新
# 2. 需要更新 → PriceUpdateWorker
#    内部调用 services/workers/getprices.py 的 run_price_update()
# 3. run_price_update() 执行:
#    a. 清空重建 market_prices 表
#    b. 拉取 /markets/prices/（1 次，兜底）
#    c. 拉取 4 区域订单簿（8 流并发）
#    d. 聚合写入 market_prices
#    e. 写入当日快照 market_volume_snapshots
```
