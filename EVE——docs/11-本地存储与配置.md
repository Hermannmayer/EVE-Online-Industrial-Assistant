### 11.3 序列化工具（GClass95）

```csharp
// GClass95 — 序列化工具类
//
// smethod_0(src, dst): GZip 压缩文件
// smethod_1(src, dst): GZip 解压
//
// smethod_4(path, DataTable): BinaryFormatter 序列化 DataTable
// smethod_5(path, ref DataTable): BinaryFormatter 反序列化 DataTable
//
// smethod_6(path, DataSet): BinaryFormatter 序列化 DataSet（保存运行时数据）
// smethod_7(path, ref DataSet): BinaryFormatter 反序列化 DataSet（加载）
//
// smethod_8(path, DealerSetting): BinaryFormatter 序列化设置
// smethod_9(path, ref DealerSetting): BinaryFormatter 反序列化设置

// 文件名约定:
// StaticsData.bin — 压缩前
// StaticsData.dam — GZip 压缩后
// BluePrints.bin / BluePrints.dam — 同上
// MapData.bin / MapData.dam — 同上
// settings.bin — 用户设置（不压缩）
```
