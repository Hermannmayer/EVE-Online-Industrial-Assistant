### 6.2 运费计算（GClass98）

#### 6.2.1 运价基准

```
高安（sec ≥ 0.5）：~300 ISK/m³
低安（0.0 < sec < 0.5）：~800 ISK/m³  
00 区（sec ≤ 0.0）：~2000 ISK/m³

最低运费：1,000,000 ISK
```

#### 6.2.2 运费计算公式

```csharp
// GClass98.smethod_0 — 基础运费计算
```

#### 6.3.2 补货建议（PageStorage_Suggest）

```csharp
// 补货建议算法
// 输入: 生产计划材料总需求 + 当前库存
//
// 对每种材料:
//   缺口 = sum(计划需求) - sum(已有库存)
//   如果缺口 > 0:
//     建议来源 = 买 / 造 / 调货
//     建议数量 = 缺口
//     优先级 = 基于缺货对生产的影响
//
// 输出:
//   - 建议采购清单（含数量、单价、总价）
//   - 建议调货清单（从哪个设施到哪个设施）
```

### 6.5 货运成本利润分析

```
货运利润 = 货运合同收入 - 运输成本

运输成本计算要素:
1. 机会成本（时间×ISK/秒费率）
2. 燃料成本（跳数×燃料单价）
3. 过路费（低安/00 区过路费）
4. 保险（高价值货物）
```
