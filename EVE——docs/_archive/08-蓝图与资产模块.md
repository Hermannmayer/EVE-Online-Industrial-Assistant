### 8.2 蓝图管理（PageBluePrints）

#### 8.2.1 蓝图导入

从 EVE 客户端剪贴板导入蓝图：

```
用户操作:
1. 游戏中打开工业界面 → 蓝图选项页
2. 全选蓝图列表 → Ctrl+C
3. 回到商人助手 → 点击"粘贴导入"

剪贴板内容格式（每行一个蓝图，Tab 分隔）:
BlueprintTypeID[TAB]ME[TAB]TE[TAB]Runs[TAB]Facility

导入后每行写入 dataSet_3.Tables["蓝图表"]:
{
    UniqueID = BlueprintTypeID + "_" + Facility,
    BlueprintID = BlueprintTypeID,
    MLevel = ME,
    TLevel = TE,
    Runs = Runs,          // -1 = 原图/无限
    Parallels = 0,
    BPcost = 0,
    Facility = Facility
}
```

#### 8.2.2 用户蓝图数据模型

```csharp
// dataSet_3.Tables["蓝图表"]
public class BlueprintOwned {
    public string UniqueID;      // 复合主键（BlueprintID_Facility）
    public int BlueprintID;      // 蓝图 typeID
    public short MLevel;         // 材料效率等级 0-20
    public short TLevel;         // 时间效率等级 0-20
    public int Runs;             // 剩余运行次数（-1=原图/无限）
    public int Parallels;        // 并行数
    public double BPcost;        // 蓝图获取成本
    public string Facility;      // 所在设施
}
```
