## 1.2 架构模式

扁平架构：**页面 + 后台 Worker 线程 + 直接 SQL**

```
Main.py (入口)
  │
  └─ MainWindow (QMainWindow)
       ├── QTreeWidget (侧边导航)
       ├── QStackedWidget (内容区)
       ├── QStatusBar (状态栏)
       └── 后台 QThread (Worker 模式)
            ├── PriceUpdateWorker
            ├── SearchWorker
            ├── OrderFetchWorker (ESI 实时订单)
            └── BPMatWorker (蓝图材料)
```

设计原则：
- 每个 QThread 只做一件事，用完即弃
- 页面之间通过 MainWindow 传参
- 极少抽象层，services/ 下是函数集合，非类

## 1.5 数据库结构

单一 `items.db`，核心表：

```sql
-- 物品（来自 SDE）
CREATE TABLE item (type_id, en_name, zh_name, group_id, volume, ...);

-- 市场价格（复合主键 type_id + region_id）
CREATE TABLE market_prices (
    type_id INTEGER NOT NULL, region_id INTEGER NOT NULL,
    buy_price REAL, sell_price REAL,
    buy_volume BIGINT, sell_volume BIGINT,
    fetch_time TIMESTAMP,
    PRIMARY KEY (type_id, region_id)
);

-- 成交量快照（按天）
CREATE TABLE market_volume_snapshots (
    type_id, region_id, date TEXT,
    buy_price, sell_price, buy_volume, sell_volume,
    PRIMARY KEY (type_id, region_id, date)
);

-- 蓝图关系
CREATE TABLE blueprint_products (blueprint_type_id, product_type_id, quantity, activity);
CREATE TABLE blueprint_materials (blueprint_type_id, material_type_id, quantity, activity);
CREATE TABLE blueprint_activities (blueprint_type_id, activity, time);
```

## 1.6 价格拉取流程

```
启动 → 检查 MAX(fetch_time) → 过期则自动更新
                                │
                         /markets/prices/（1 次，兜底价）
                                │
                 并发拉取 4 区域订单簿（8 条流：4 区域 × 2 方向）
                                │
                        聚合为 (type_id, region_id) 粒度的买/卖价
                                │
                        写入 market_prices + 当日快照
```
