### 3.1 价格体系总览

市场价格是整条系统的"血液"——所有制造决策、交易建议、利润计算都依赖实时市场价格。

```
ESI API（远程）
    │ HTTP GET（并发拉取，限流 150 req/s）
    ▼
价格拉取模块（定时调度）
    │ 聚合各区域订单
    ▼
缓存层（按 type_id + region_id 索引）
    ├── 买/卖价
    ├── 买卖盘深度
    └── 成交量历史
    │
    ▼
价格查询接口 → 制造评分 / 贸易评分 / 各类建议
```

### 3.2 ESI 核心端点

| 端点 | 用途 |
|------|------|
| `GET /markets/{region_id}/orders/?order_type=buy\|sell&page=N` | 区域买卖订单（分页） |
| `GET /markets/{region_id}/history/` | 历史价格/成交量 |
| `GET /markets/prices/` | CCP 调整价 + 均价（兜底） |

| `GET /industry/systems/` | 工业系统指数 |

### 3.3 价格拉取逻辑

```
OnTimer（每 ~60 秒）:
    for each region in 交易区域:
        1. 检查该区域上次拉取时间
        2. 如果距今时间 > 过期阈值:
            3. 拉取 /orders/?order_type=sell 所有分页
            4. 拉取 /orders/?order_type=buy 所有分页
            5. 聚合计算:
                - sell = min(卖单价格)  → 卖一价
                - buy = max(买单价格)   → 买一价
                - sell_vol = sum(卖单量) → 卖方深度
                - buy_vol = sum(买单量)  → 买方深度
                - sell_count = 卖单数量  → 卖方热度
                - buy_count = 买单数量
            6. 更新缓存 PV/PVMore 表
            7. 标记该区域更新完成
```

### 3.4 缓存过期策略

通过两张时间戳表控制：

- `TimeStamps`: 记录各数据集最后更新时间及就绪标记
- `TimeStampsWEIGHT`: 记录各区域命中率、延迟秒数，动态调整拉取频率

```
过期判断（GClass138.smethod_1）:
    当前时间 - 上次更新时间 > 过期阈值 → 需要刷新
    
    DataUpESI 中还检查:
    该区域命中率 > 50% → 正常拉取
    该区域命中率 ≤ 50% → 降低拉取频率
```

```python
# 评估一个物品的跨区域套利/买卖建议
def evaluate_item(type_id, buy_region, sell_region):
    buy_price = get_price(type_id, buy_region, "buy")
    sell_price = get_price(type_id, sell_region, "sell")
    depth = get_market_depth(type_id, sell_region)
    volume = get_volume_30d(type_id, sell_region)
    
    is_liquid = volume >= 100 and depth["sell_volume"] >= 10
    
    if sell_price > buy_price * 1.1 and is_liquid:
        action = "buy"  # 建议买入
    else:
        action = "hold"
```

```python
def get_price(type_id, price_type, hub=None):
    """从 market_prices 表查询价格
    price_type: 'buy' → buy_price, 'sell' → sell_price
    hub: 'Jita' / 'Amarr' / None（任意区域）
    降级策略：如果指定区域无数据，取任意区域
    """
    col = "buy_price" if price_type == "buy" else "sell_price"
    conn = sqlite3.connect(DB_PATH)
    c = conn.cursor()
    if hub:
        rid = TRADE_HUB_IDS[hub]
        c.execute(f"SELECT {col} FROM market_prices WHERE type_id=? AND region_id=? LIMIT 1", (type_id, rid))
        row = c.fetchone()
        if row and row[0] is not None:
            return row[0]
        # 降级：取任意区域
        c.execute(f"SELECT {col} FROM market_prices WHERE type_id=? AND {col} IS NOT NULL LIMIT 1", (type_id,))
    else:
        c.execute(f"SELECT {col} FROM market_prices WHERE type_id=? AND {col} IS NOT NULL LIMIT 1", (type_id,))
    row = c.fetchone()
    return row[0] if row else None
```
