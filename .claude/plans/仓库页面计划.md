# Plan: 仓库页面（库存管理）

**Complexity**: Large  
**Source**: EVE——docs/06-物流与仓储模块.md + 用户需求

---

## 需求重述

重构仓库页面，从当前"物品浏览列表"改为完整的**多机库库存管理系统**：

1. **分机库管理** — 多个仓库（如"矿仓"、"组件仓"），各独立管理
2. **工业制造读取库存** — IndustryPage 材料汇总时可扣除选定库存
3. **移动库存** — 机库间转移（多选）
4. **剪贴板粘贴导入** — 从游戏复制格式粘贴
5. **结算成本** — 按卖价/买价/打折率算总价
6. **采购助手** — 预留
7. **删除行** — 右键/选中删除
8. **导入自动记录价格** — 自动从 market_prices 获取当前价
9. **均价计算** — 多次导入按加权平均

---

## 数据结构

```sql
CREATE TABLE IF NOT EXISTS hangars (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    notes TEXT DEFAULT ''
);
CREATE TABLE IF NOT EXISTS inventory_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    hangar_id INTEGER NOT NULL,
    type_id INTEGER NOT NULL,
    quantity INTEGER NOT NULL DEFAULT 0,
    cost_price REAL DEFAULT 0,
    total_cost REAL DEFAULT 0,
    created_at TEXT,
    FOREIGN KEY (hangar_id) REFERENCES hangars(id)
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_inv_item ON inventory_items(hangar_id, type_id);
```

### Task 3: 各功能实现

- **机库 CRUD** — QComboBox + 按钮操作，切换即刷新
- **表格 + 右键菜单** — QTableView + QMenu（编辑/删除/移动）
- **粘贴导入** — 支持 `type_id[TAB]数量` 和 `中文名[TAB]数量`，多行
- **移动库存** — 选中 → 选目标机库 → 确认
- **结算栏** — QButtonGroup 单选，QLineEdit 折扣，实时重算
- **删除** — 选中行或右键删除，确认弹窗
