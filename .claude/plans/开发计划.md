## Phase 1：制造评分完善（当前模块增强）

> 对应：04-工业制造核心算法 · 14-实施路线图

### 1.1 ME/TE 等级纳入评分

**参考**: 04 文档 §4.2.1 GClass57（`int_3=ME`, `int_4=TE`）

**文件**: `services/scoring.py` → `calc_manufacturing_score()`

- 参数增加 `me_level: int = 0, te_level: int = 0`
- 材料数量修正 = 基础数量 × (1 - 浪费因子 × (1 - 0.05 × ME))
- 制造时间修正 = 基础时间 × (1 - 0.02 × TE)
- 当前 `blueprint_materials` 已有浪费因子数据

**复杂度**: 低（纯算法，~30 行）

### 1.2 评分 UI 面板

**文件**: `ui_pyside6/views/industry_view.py`

- 结果区增加评分分解显示（`profit_score`, `volume_score`, `efficiency_score`, 总分）
- 增加 ME/TE 输入框（`QSpinBox` 0-20）
- 原料区域下拉框（当前硬编码 Jita → 可选四大贸易中心）
- 产品销售区域下拉框

**复杂度**: 中

### 1.3 工厂设施税率

**参考**: 04 文档 §4.3 GClass61 + GClass68

- `calc_manufacturing_score` 已有 `facility_tax_pct` 参数，确认其正确传入 UI
- 读取 `industry_facilities` 表供选择

## 依赖关系图

```
Phase 1（评分增强）
    │
    ▼
Phase 2（BOM + 排行）─→ Phase 3（蓝图管理）─→ Phase 4（物流仓储）
                            │                      │
                            ▼                      ▼
                        Phase 5（市场交易）←── Phase 6（置顶窗口）
                                                      │
                                                      ▼
                                                 Phase 7（配置整合）
```

- Phase 1→2：连续（先增强评分函数）
- Phase 2→3：独立
- Phase 3→4：弱依赖（仓储需要蓝图数据）
- Phase 4→5：独立
- Phase 5→6：连续（订单是置顶窗口数据基础）
- Phase 7：可随时进行
