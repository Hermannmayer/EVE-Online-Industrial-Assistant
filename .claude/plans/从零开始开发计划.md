## 你需要先了解的几个概念

在开始之前，先花 10 分钟理解这几个词，后面会反复用到：

| 术语 | 大白话解释 |
|------|-----------|
| **Python 文件 (.py)** | 就是"一个记事本文件"，里面写的是 Python 代码 |
| **函数 (def)** | 像"榨汁机"：你放水果进去 → 它执行操作 → 输出果汁 |
| **类 (class)** | 像"模具"：你定义好一个类，就能用它批量制作长得一样的对象 |
| **import** | 拿来主义：别人写好的功能，你通过 import 直接拿来用 |
| **SQLite** | 一个"文件型数据库"——就是个文件，Python 可以直接读写它 |
| **PySide6** | 一个"做图形界面的工具箱"。按钮、窗口、输入框都是它提供的 |
| **虚拟环境 (venv)** | 给每个项目单独装一套 Python 工具，互不干扰 |

### Step 1.2 — 加一个按钮，点击后改文字

把 `hello.py` 改成这样：

```python
"""
按钮点击示例
"""
import sys
from PySide6.QtWidgets import (
    QApplication, QMainWindow, QPushButton,
    QLabel, QVBoxLayout, QWidget,
)


def on_button_click():
    """按钮被点击时执行这个函数"""
    label.setText("你点了我一下！")


# 创建 APP
app = QApplication(sys.argv)

# QMainWindow 是"主窗口"
window = QMainWindow()
window.setWindowTitle("按钮示例")
window.resize(400, 300)

# 在窗口里放一个"容器"（central widget）
central = QWidget()
window.setCentralWidget(central)

# 布局：让控件竖着排列
layout = QVBoxLayout(central)

# 添加一个标签
label = QLabel("这是一段文字")
layout.addWidget(label)

# 添加一个按钮
button = QPushButton("点我")
button.clicked.connect(on_button_click)  # 把按钮的点击和函数连起来
layout.addWidget(button)

# 显示窗口
window.show()
sys.exit(app.exec())
```

**运行**：`python hello.py`

**你学到了**：
- `QMainWindow` → 主窗口（你打开一个软件时的那个窗口）
- `QPushButton` → 按钮
- `QVBoxLayout` → 垂直布局（控件从上往下排）
- `QWidget` → 一个"容器"（装其他控件的盒子）
- `.clicked.connect(函数)` → 把"按钮被点击"和你的代码连起来

> **新手常见疑问**：`layout.addWidget(label)` 就是把 `label` 这个控件放进 `layout` 这个布局里，好比把一张照片放进相框。

```python
"""
学习目标：导航切换页面
"""
import sys
from PySide6.QtCore import Qt
from PySide6.QtWidgets import (
    QApplication, QMainWindow, QWidget, QVBoxLayout, QHBoxLayout,
    QListWidget, QStackedWidget, QLabel,
)


class FirstWindow(QMainWindow):
    """你自己的第一个主窗口"""

    def __init__(self):
        super().__init__()
        self.setWindowTitle("EVE 助手 — 学习版")
        self.resize(800, 500)

        # 中心容器
        central = QWidget()
        self.setCentralWidget(central)

        # 水平布局：左边导航 + 右边内容
        layout = QHBoxLayout(central)
        layout.setContentsMargins(0, 0, 0, 0)

        # 左边：导航列表
        self.nav_list = QListWidget()
        self.nav_list.addItem("🏠 首页")
        self.nav_list.addItem("📦 物品查询")
        self.nav_list.addItem("🏭 工业制造")
        self.nav_list.setFixedWidth(150)
        layout.addWidget(self.nav_list)

        # 右边：页面容器（QStackedWidget = 多页切换器）
        self.pages = QStackedWidget()
        layout.addWidget(self.pages)

        # 创建三个页面（目前只是占位文字）
        self.page_home = QLabel("这是首页\n欢迎使用 EVE 助手")
        self.page_home.setAlignment(Qt.AlignmentFlag.AlignCenter)
        self.pages.addWidget(self.page_home)

        self.page_items = QLabel("物品查询页面\n（以后会变成搜索框+表格）")
        self.page_items.setAlignment(Qt.AlignmentFlag.AlignCenter)
        self.pages.addWidget(self.page_items)

        self.page_industry = QLabel("工业制造页面\n（以后会变成利润计算器）")
        self.page_industry.setAlignment(Qt.AlignmentFlag.AlignCenter)
        self.pages.addWidget(self.page_industry)

        # 当点击导航项时切换页面
        self.nav_list.currentRowChanged.connect(self.pages.setCurrentIndex)


if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = FirstWindow()
    window.show()
    sys.exit(app.exec())
```

**运行**：`python ui_pyside6/my_first_window.py`

**你学到了**：
- `QListWidget` → 列表（点哪一项就选中哪一项）
- `QStackedWidget` → 页面容器（像一叠纸，只能看到最上面那一张）
- `currentRowChanged.connect(...)` → 当选中行变化时触发切换
- 用 `class` 把窗口打包成一个"整体"，以后用 `FirstWindow()` 就能创建它

### Step 2.2 — 用 Python 连接数据库并查询

新建文件 `learn_db.py` 在项目根目录：

```python
"""
学习目标：连接数据库，执行查询
"""
import sqlite3

# 1. 连接数据库（如果文件不存在会自动创建）
conn = sqlite3.connect("database/items.db")

# 2. 创建一个"指针"（cursor）——用来执行 SQL
cursor = conn.cursor()

# 3. 查询有哪些表
cursor.execute("SELECT name FROM sqlite_master WHERE type='table'")
tables = cursor.fetchall()
print("数据库中的表：")
for t in tables:
    print(f"  - {t[0]}")

# 4. 查询 item 表前 5 行
cursor.execute("SELECT type_id, en_name, zh_name FROM item LIMIT 5")
rows = cursor.fetchall()
print("\n前 5 个物品：")
for row in rows:
    print(f"  ID={row[0]}, 英文={row[1]}, 中文={row[2]}")

# 5. 查一个具体物品
type_id = 34  # 三钛合金
cursor.execute("SELECT zh_name, volume FROM item WHERE type_id = ?", (type_id,))
name, vol = cursor.fetchone()
print(f"\ntype_id={type_id} → {name}, 体积={vol} m³")

# 6. 关闭连接
conn.close()
```

**运行**：`python learn_db.py`

**你学到了**：
- `sqlite3.connect("文件路径")` → 打开数据库
- `cursor.execute("SQL语句")` → 执行查询
- `cursor.fetchall()` → 取回所有结果
- `cursor.fetchone()` → 取回第一行结果
- `?` 占位符 → **永远不要用 f-string 拼 SQL！** 用 `?` 防止注入

> 🔐 **安全提示**：SQL 注入就像有人在你查数据库时偷偷改你的查询语句。用 `?` 就安全了。

## Phase 3：制造利润计算器（5-7 天）

> 目标：理解"计算逻辑"是如何工作的

### Step 3.1 — 什么是"制造评分"？

核心公式：

```
利润 = 产品卖出价 - 材料成本 - 税费 - 经纪人费

评分由三部分组成：
1. 利润率得分 = min(利润率 × 4, 40)   —— 利润率越高分越高
2. 成交量得分 = min(成交量/500万, 1) × 30 —— 越活跃分越高
3. 效率得分 = min(时均利润/5000万, 1) × 30 —— 每小时赚得越多分越高
总分 = 利润得分 + 成交量得分 + 效率得分（满分 100）
```

### Step 3.2 — 读懂 `calc_manufacturing_score`

打开 `services/scoring.py` 第 110-291 行的 `calc_manufacturing_score`。

这个函数做了 8 件事：

1. **查蓝图** → 这个物品用什么蓝图造（line 149-156）
2. **查价格** → 成品能卖多少钱（line 165-166）
3. **查材料** → 造这个需要哪些材料（line 172-176）
4. **算成本** → 所有材料总价（line 183-193）
5. **算费率** → 角色技能影响的手续费（line 200-217）
6. **算利润** → 收入 - 全部成本（line 220-229）
7. **算评分** → 利润 + 成交量 + 效率（line 258-263）

> 💡 **调试技巧**：在第 166 行前面加一行 `print(f"成品价格：{prod_price}")`，运行后再看终端输出，你就知道 `prod_price` 这个变量装的是什么值了。

### Step 3.3 — 自己写一个小评分函数

新建 `my_score.py`，写一个简化版：

```python
"""
练习：简化的利润计算
"""
def simple_profit(product_price, material_cost, quantity=1):
    """简单利润计算"""
    revenue = product_price * quantity
    cost = material_cost * quantity
    profit = revenue - cost

    if cost == 0:
        margin = 0
    else:
        margin = (profit / cost) * 100

    return {
        "profit": round(profit, 2),
        "margin_pct": round(margin, 2),
    }

# 测试
result = simple_profit(product_price=10, material_cost=6, quantity=1000)
print(f"利润：{result['profit']} ISK")
print(f"利润率：{result['margin_pct']}%")
```

**运行**：`python my_score.py`

**你学到了**：
- 函数可以**返回一个字典**（`dict`）——带名字的盒子，里面装很多值
- `return` 把计算结果交还给调用方
- 测试一个函数不需要 GUI，`print` 就够

## Phase 4：价格数据拉取（4-5 天）

### Step 4.1 — 什么是 ESI？

EVE Online 提供了官方 API（叫 ESI）。你向特定网址发请求，就能获取游戏数据。

比如：  
`https://esi.evetech.net/latest/markets/10000002/orders/?order_type=sell&page=1`

这个网址的意思是：给我 Jita 区域（10000002）的卖单第一页。

### Step 4.2 — 最简单的网络请求

新建 `learn_http.py`（需要先 `pip install requests`）：

```python
"""发送 HTTP 请求获取 ESI 数据"""
import requests

url = "https://esi.evetech.net/latest/markets/prices/"
resp = requests.get(url, headers={"User-Agent": "EveApp/1.0"})
data = resp.json()
print(f"返回了 {len(data)} 个物品的参考价格")
```

**运行**：先 `pip install requests` 再 `python learn_http.py`

**你学到了**：
- 发 HTTP 请求 = 向某个网址要数据
- `resp.json()` 把 JSON 数据变成 Python 字典/列表

> ⚠️ 项目用的是 `aiohttp`（异步版本），比 `requests` 复杂但更快。初学阶段先理解"发请求→拿回数据"的概念。
